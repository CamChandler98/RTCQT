`SelectTrack(TrackId)` rejects unknown, duplicate, looping, incomplete,
mismatched, or unqueryable pairs before stopping current playback. Validation
requires matching duration and the analyzer's configured number of finite normalized bands (1–96). Selecting a playing
or paused current track preserves it; Restart explicitly restarts it. A stopped
track can be started with Play or selected again.

Switch/restart retires the old Audio Component, clears the visual instances,
assigns the SoundWave/analyzer pair, creates the sole new Audio Component, and
plays at zero. A new component ID prevents queued old callbacks from advancing
a restarted instance of the same SoundWave. No temporary effects are spawned.
The existing response settings and material pipeline remain in use.

The installed engine implements `FMixerSource::GetPlaybackPercent()` as
`(StartFrame + GetNumFramesPlayed()) / NumTotalFrames` in
`Engine/Source/Runtime/AudioMixer/Private/AudioMixerSource.cpp`. `Audio.cpp`
dispatches that percentage to the originating component ID on the game thread.
The manager converts it to song seconds and evaluates the active analyzer
directly. It never accumulates frame delta time. This source follows mixer
sample consumption; callback delivery and device output buffering can introduce
latency. Recognizable audible/visual alignment still needs a listening check.
Recycled mixer voices can briefly report an old frame count. A monotonic wall
time bound rejects positions ahead of elapsed unpaused playback time, with a
0.25-second allowance. Wall time never supplies the visual evaluation position.
Regular non-looping imported WAVs are supported; there is no fallback clock
for devices/formats that fail to deliver playback callbacks.

Dropdown options map to stable IDs. Duplicate labels get visible numeric
suffixes; labels are never used to resolve assets. Invalid entries and
ambiguous IDs are omitted. Programmatic dropdown initialization and status
updates do not invoke track selection.

## Band counts and custom weights

Playback reads Num Bands from the active analyzer. Switches rebuild the exact
number of cubes, retain the authored line's center span, and shrink bar width
when necessary. `Keep Playback Line Width` can be disabled on the visualizer
for fixed-spacing behavior. `Playback Reference Band Count` defaults to 32,
the count the original line was authored for. One band is centered at the origin.
Offline Sequencer layout behavior remains unchanged.

Open `/Game/Audio/PrivateTest/MusicLab/DA_MusicLabResponse` to tune the demo.
The setup script creates this independent copy and preserves your edits on
reruns. Under **Frequency Weights**, three neutral ranges are ready to edit:

| Label | Min Hz (inclusive) | Max Hz (exclusive) | Default gain |
| --- | --- | --- | --- |
| Bass | 20 | 250 | 1 |
| Mid | 250 | 4000 | 1 |
| Treble | 4000 | 20000 | 1 |

Start by changing Bass gain to **1.5**, or Treble to **0.7**, then Play again.
Gain 1 is neutral; 0 removes a range's visual response (bars stay at minimum
height); values above 1 emphasize it. These gains affect visuals, not the audio. These are
linear control gains, not decibels. Gains apply before the response exponent
and clamp, so strong emphasis can saturate the response. No NRT reanalysis is
needed for response-weight edits.

Frequency ranges select bands by their actual CQT center frequency:
`StartingFrequency * 2^(band_index / BandsPerOctave)`. Their meaning survives
changes to band count or CQT spacing. Add named ranges for finer control.
Overlapping ranges multiply; invalid ranges are ignored and range gains are
bounded to [0, 8]. The public `ResolveBandWeights` function previews effective
gains for a supplied analyzer grid and provides a single extension point for
future curves or presets.

**Band Weights** remains an optional index-based array: element 0 controls the
lowest band. Missing entries default to 1; extra entries are unused. Index
weights multiply the frequency gains. Prefer frequency ranges when using
different analyzer grids; leave the index array empty until you need exact
bin control. Clearing Frequency Weights restores the existing index-only path.
